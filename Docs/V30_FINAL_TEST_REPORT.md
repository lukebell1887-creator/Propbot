## Trading windows — only ~2 hours per symbol per day, 5 days/week

The bot is locked to its windows by **three independent gates**:

| Gate | What it blocks | Source |
|---|---|---|
| `TradingCalendar.weekend` | Fri 21:00 UTC → Sun 22:00 UTC, no entries | `src/trading_calendar.py:141` |
| `TradingCalendar.rollover` | Daily broker rollover blackout (~21:55–22:05 UTC) | `src/trading_calendar.py:142` |
| Per-symbol ORB `trade_window_minutes=120` | 2-hour entry window after OR finalisation | `V30_ORB_CONFIGS` |
