### 6. Feed ATR + run partial manager on each closed M1 bar (line ~801)

In `_process_bar` (or wherever each new closed M1 bar is consumed),
**before** the existing entry-decision block, add:

```python
        # v30.3 — feed ATR tracker every bar (always, regardless of position)
        st.atr_tracker.update(float(bar.high), float(bar.low), float(bar.close))

        # v30.3 — if a position is open, run the partial-close ladder
        if st.open_ticket is not None and st.partial_state is not None:
            res = self.partial_mgr.update(
                state=st.partial_state,
                bar_high=float(bar.high),
                bar_low=float(bar.low),
                bar_close=float(bar.close),
                atr_value=st.atr_tracker.value,
                atr_ready=st.atr_tracker.ready,
                bridge=self.bridge,
                round_lots_fn=self._round_lots,    # add a tiny helper if not present
            )
            if res.tp1_fired:
                self._log_event("TP1_PARTIAL", symbol=sym, ticket=st.open_ticket,
                                lots_closed=st.partial_state.original_lots * 0.5)
                st.open_size_lots = st.partial_state.open_lots   # keep mirror in sync
                st.open_sl = st.partial_state.sl                 # SL moved to BE
            if res.tp2_fired:
                self._log_event("TP2_PARTIAL", symbol=sym, ticket=st.open_ticket,
                                lots_closed=st.partial_state.original_lots * 0.25)
                st.open_size_lots = st.partial_state.open_lots
            if res.sl_moved:
                st.open_sl = st.partial_state.sl
                self._log_event("TRAIL_SL", symbol=sym, ticket=st.open_ticket,
                                new_sl=st.partial_state.sl)
            if res.error:
                log.error("[PARTIAL_MGR] %s: %s", sym, res.error)
```

The `_round_lots` helper (add as a method on the runner class):

```python
    def _round_lots(self, lots: float) -> float:
        """Round to broker lot step (default 0.01). Override in subclass if needed."""
        return round(lots, 2)
```

### 8. `_infer_broker_close_px` — broker close is now SL only (line ~1100-1140)

After v30.3, the broker's `tp` is 0.0. So a `POS_CLOSED_BY_BROKER` event
must be an SL hit (which may be the original SL, BE, or a trail SL —
all stored in `st.open_sl`). Replace the function body with:

```python
    def _infer_broker_close_px(self, st) -> Tuple[float, str]:
        """v30.3 — broker close = SL hit (original / BE / trail). TP exits are managed in-bar."""
        if st.open_sl is None:
            return float(st.last_m1_close or 0.0), "m1_close_fallback"
        return float(st.open_sl), "sl_hit"
```

(The old TP1-vs-SL nearest-edge logic is no longer needed because TP1
fires inside `_process_bar` via the partial manager and is logged
as `TP1_PARTIAL`, not as `POS_CLOSED_BY_BROKER`.)

## Rollback plan

If anything misbehaves: `git revert <integration-commit>` and the bot
reverts to v30.x TP1-only behaviour with no broker-state inconsistency
(broker TP was already removed in step 4 — but partial manager is the
only thing that closes TP1, so reverting puts TP1 back at the broker).

## Why we're confident

- **24 unit tests** cover every TP1/TP2/trail edge: idempotency, broker
  failure, lot rounding, persistence round-trip, full-ladder simulation.
- The partial manager is **side-effect-only via a `bridge` argument** —
  same code path runs in tests with `FakeBridge` and live with `MT5Bridge`.
- ATR tracker is a **pure Wilder implementation** seeded from warmup
  history — no look-ahead, persistable across restarts.

The remaining work is purely "wire it up". This document is the wiring diagram.
