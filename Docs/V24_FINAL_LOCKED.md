## What the sizer actually does at runtime

The Merton×GZ formula is:

```
f(t) = min( cap_mult × base ,
            base × merton_mult(t) × gz_barrier(t) )

merton_mult(t) = max(0, μ̂_ewma / (γ · σ̂²_ewma)) / base
gz_barrier(t)  = max(0, 1 − DD(t) / DD_cap)
```

Smoke-test proof (just ran):

| State                       | Risk per trade |
| --------------------------- | -------------- |
| Warmup (< 15 closed trades) | 0.110 %        |
| 20+ trades, DD = 0 %        | **0.550 %** ← cap binds |
| 20+ trades, DD = 2 %        | 0.550 %   (GZ × 0.5, but Merton mult large → cap still binds) |
| 20+ trades, DD ≈ 4 %        | **0.000 %** ← GZ absorbing barrier, sizer stops trading |
